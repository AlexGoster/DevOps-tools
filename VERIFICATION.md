# Проверка DevOps-tools

22 октября: 11 тестов прошли: `python -m pytest`.

SSH больше не принимает неизвестные ключи автоматически: загружается known_hosts,
применяется RejectPolicy; поддержан отдельный файл known_hosts. Два новых теста
проверяют отказ неизвестному серверу и параметры подключения/закрытие клиента.
Paramiko-клиент имитируется; подключения к реальным серверам не выполнялись.

Проверены локальные CPU/RAM/disk, CLI, бэкап файла/каталога, повторный бэкап, защита от вложенного назначения и сохранение посторонних каталогов. Только временные тестовые файлы; SSH/deploy не выполнялись.

Команды установки и запуска в README соответствуют проверенным маршрутам CLI.

Логика срока SSL-сертификата проверена с тестовой имитацией; меньше суток до истечения не считается истёкшим сертификатом. Времена сравниваются в UTC.
